# content/

Paste `.md` files here. Every `.md` file in this folder (subfolders included) is indexed
for the chat, except this README.

Tips for good answers:

- Use headings (`##`). Chunks are split at headings, and the heading is shown as the source.
- One topic per file works well: `about.md`, `projects.md`, `experience.md`, `faq.md`.
- Write facts plainly. The model grounds biographical claims here and can interpret
  the profile for open-ended questions, without preambles about missing source material.

- A line that is only an italic note in brackets, like `_(pending)_`, is skipped. Use it for
  unanswered questions or notes to yourself; sections with nothing else in them are left out.

In dev, changes are picked up on the next question with no restart. In production, redeploy.
